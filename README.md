# University Project — Gestion Universitaire

Application Spring Boot de gestion des étudiants, notes, absences et attestations.

## Stack
- Backend : Java 11, Spring Boot, Spring Data JPA, Spring Security
- Base de données : MySQL / PostgreSQL
- Frontend : Thymeleaf / React (à préciser)
- Build : Maven

## Fonctionnalités
- Gestion des étudiants (CRUD)
- Gestion des notes et absences
- Génération d'attestations
- Chat interne (ChatController / ChatService)
- NewsTicker

## Lancement
\`\`\`bash
git clone https://github.com/wassimkhazri1/university-project
cd university-project
./mvnw spring-boot:run
\`\`\`
